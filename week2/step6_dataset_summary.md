# 데이터셋 요약 (2주차 과제 ③)

- 전체 시행(파일) 수: 250 (피험자 A~E × 각 50시행)
- 시행 단위 분할(누수 방지, `train_test_split(..., stratify=labels, random_state=42)`):
  학습 200시행 / 테스트 50시행 (8:2)
- 윈도우 분할 후 샘플 수: 학습 3800개(200×19) / 테스트 950개(50×19)
- 입력 텐서 형태: `(N, 3, 32, 300)`
- 학습/테스트 시행 파일 중복 개수: 0 (누수 없음 확인)

## 클래스별 분포 (윈도우 샘플 기준)

| 피험자(label) | 학습 샘플 수 | 테스트 샘플 수 |
|---|---|---|
| A (0) | 760 | 190 |
| B (1) | 760 | 190 |
| C (2) | 760 | 190 |
| D (3) | 760 | 190 |
| E (4) | 760 | 190 |
| **합계** | **3800** | **950** |

각 피험자가 학습·테스트에 정확히 동일 비율(190×4=760, 190개)로 들어가 있어
`stratify` 옵션이 의도대로 동작했음을 확인했다.
